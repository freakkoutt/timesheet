# Система учета рабочего времени (Timesheet)

Корпоративная система для учёта отработанных сотрудниками часов. Проект позволяет вести детальную статистику по задачам и проектам, запускать таймер для отслеживания времени в реальном времени, а также формировать отчёты для расчета заработной платы с возможностью утверждения руководителем.

## Возможности

- **Учет рабочего времени:** Внесение записей о затраченном времени с указанием даты, проекта, задачи и подробным описанием.
- **Таймер реального времени:** Встроенный таймер, позволяющий запускать и останавливать отсчет времени, автоматически создавая запись в табеле.
- **Управление проектами:** Создание и ведение базы проектов и задач внутри них.
- **Отчетность:** Генерация детализированных отчетов за выбранный период (день, неделя, месяц) для анализа трудозатрат.
- **Модерация:** Реализован процесс согласования: сотрудник отправляет часы на проверку, руководитель утверждает или отправляет на доработку.
- **Расчет зарплаты:** Формирование итоговых данных для бухгалтерии на основе утвержденных часов.

## Сущности системы

Проект построен на трех основных сущностях:

1.  **Сотрудник (Employee)**
    - Персональные данные, контактная информация, должность, ставка.
    - Привязка к пользователю системы для аутентификации.
2.  **Проект / Задача (Project / Task)**
    - **Проект:** Название, клиент, статус (активен/закрыт).
    - **Задача:** Принадлежит проекту, название, описание, плановая оценка.
3.  **Запись времени (Time Entry)**
    - Ссылка на сотрудника, проект и задачу.
    - Дата выполнения работы.
    - Количество затраченных часов (в десятичном формате, например, 2.5).
    - Текстовое описание выполненной работы.
    - Статус записи (на проверке/утверждено/отклонено).

## Роли пользователей

В системе предусмотрено разделение прав доступа для двух типов пользователей:

| Роль | Права и возможности |
| :--- | :--- |
| **Сотрудник** | - Запуск/остановка таймера.<br>- Ручное добавление, редактирование и удаление *своих* записей.<br>- Просмотр личного табеля и статистики.<br>- Отправка заполненного табеля на утверждение руководителю. |
| **Руководитель** | - Все права сотрудника (может вести свой учет).<br>- Просмотр записей всех сотрудников своего отдела/проекта.<br>- Утверждение или отклонение отправленных табелей.<br>- Формирование сводных отчетов по команде для расчета зарплаты. |

## Начало работы

Следуйте этим инструкциям, чтобы запустить копию проекта локально для разработки и тестирования.


### Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    cd your-repo-name
    ```

2.  **Настройте переменные окружения:**
    Скопируйте файл `.env.example` в `.env` и отредактируйте его, указав параметры подключения к базе данных и другие секреты.
    ```bash
    cp .env.example .env
    ```

3.  **Запустите инфраструктуру (Docker):**
    *(Если используется)*
    ```bash
    docker-compose up -d
    ```

4.  **Установите зависимости и запустите приложение:**
    *(Команды зависят от вашего стека, пример для Node.js)*
    ```bash
    # Для backend
    cd backend
    npm install
    npm run start:dev

    # Для frontend (в новом терминале)
    cd frontend
    npm install
    npm run dev
    ```

Приложение будет доступно по адресу `http://localhost:3000` (или другому, указанному в конфигах).

## Использование

1.  **Регистрация:** Войдите в систему под учетной записью сотрудника или руководителя.
2.  **Запуск таймера:** На главной странице нажмите "Старт", выберите проект/задачу и начните работу. По окончании нажмите "Стоп" — запись автоматически добавится в список.
3.  **Заполнение табеля:** Перейдите в раздел "Мои часы". Добавьте недостающие записи вручную, если забыли включить таймер.
4.  **Отправка на утверждение:** В конце отчетного периода (например, в пятницу) нажмите кнопку "Отправить на проверку". После этого руководитель увидит ваш табель.
5.  **Утверждение (для руководителя):** Зайдите в раздел "Табелы сотрудников", просмотрите присланные данные и нажмите "Утвердить" или "Вернуть на доработку".
6.  **Отчеты:** Перейдите в раздел "Отчеты", выберите период и сотрудника для формирования сводки.
